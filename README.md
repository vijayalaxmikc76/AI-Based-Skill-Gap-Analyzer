# AI-Powered Adaptive Career Intelligence & Skill Gap Analyzer

An AI-powered platform that analyzes resumes, identifies skill gaps, evaluates competencies, and generates personalized career development roadmaps based on job market requirements.

## Project Modules

1. Resume Intelligence and NLP
2. Job Market Intelligence and Skill Gap Analysis
3. Adaptive Skill Assessment
4. Skill Knowledge Graph and Career Recommendations

## Technology Stack

- Frontend: React + Vite
- Backend: Python + FastAPI
- Database: PostgreSQL
- AI/ML: NLP, Machine Learning, Knowledge Graphs

## Project Goal

To bridge the gap between an individual's existing skills and the skills demanded by the industry through intelligent, evidence-based career guidance.
